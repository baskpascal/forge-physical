AI coding agents can ship software. We built one that can also take a physical-product request through hardware specification, real ESP32 firmware compilation, deterministic Wokwi testing, and evidence-backed artifacts on Google Cloud.

Coup / Forge Physical uses Gemini 3.5 Flash + Google ADK, Cloud Run Jobs, Firestore, Cloud Storage, PlatformIO and Wokwi CI. The demo proves an ESP32 temperature alarm by driving 25°C → 35°C and checking the actual alarm GPIO and serial output—not just a successful process exit.

Built for the All Things Agentic Hackathon. Project: https://forge-web-rldj6ghw7q-uc.a.run.app · Build story: https://forge-web-rldj6ghw7q-uc.a.run.app/build-story
